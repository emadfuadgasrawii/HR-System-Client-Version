## خطوات التثبيت على Bluehost

### 1. رفع الملفات
1. قم بتسجيل الدخول إلى حساب Bluehost
2. انتقل إلى File Manager
3. ارفع جميع الملفات من مجلد `dist` إلى مجلد `public_html`
4. ارفع ملف `server.ts` إلى مجلد `public_html`

### 2. إعداد قاعدة البيانات
1. أنشئ قاعدة بيانات جديدة في Bluehost
2. قم بتشغيل ملف `setup-database.sql` لإنشاء الجداول الضرورية
3. تأكد من إنشاء مستخدم قاعدة بيانات وصلاحيات الوصول

### 3. تحديث إعدادات السيرفر
في ملف `server.ts`، قم بتحديث:
- معلومات اتصال قاعدة البيانات
- منفذ السيرفر (Port)
- أي إعدادات أخرى ضرورية

### 4. تشغيل السيرفر
```bash
npm install
npm run build
npm start
```

## تثبيت التطبيق كتطبيق على الجهاز

### على متصفح Chrome/Edge:
1. افتح الموقع في المتصفح
2. اضغط على أيقونة التثبيت في شريط العنوان
3. اضغط "تثبيت"

### على متصفح Safari (iPhone/iPad):
1. افتح الموقع في Safari
2. اضغط على زر المشاركة
3. اضغط "إضافة إلى الشاشة الرئيسية"
